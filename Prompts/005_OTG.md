# OTG Mode

* Raspberry Pi is now connected to this computer using a USB Type-C
* You must write the code to enable OTG on this Raspberry Pi's Type-C
* You must then write a simple, static, test website that checks we can
  connect to the Rasspberry Pi using WebSerial.
* Once connected, I should be able to select an image, upload it to the
  website and that will send it trough WebSerial to Pi.
* Pi will then render the image on the screen using the code you wrote.


## Limitations

* Store the image in /tmp so it will be deleted later
* The program should still initially show the test image until anything is uploaded
* There shouldn't be a lot of design in the webpage as it is, for now, just
  for testing
